**Plants vs. Zombies: All-Star Premium Edition** 是一次对经典策略游戏的极致现代化复刻。本项目基于 **Phaser 3** 游戏引擎，融合了前卫的 **Glassmorphism (毛玻璃)** 视觉美学与严谨的底层逻辑重构，旨在提供一个比原版更稳定、更丝滑、更具沉浸感的保卫脑子大作战。

---

## ✨ 核心特性

-   **💎 全明星战略深度**：
    -   **20 种植物**：涵盖资源生产、远程火力、冰冻控制、群体爆发及特殊辅助（如地刺、魅惑菇）。
    -   **10 种僵尸**：从基础单位到撑杆跳、读报狂暴、舞者召唤、矿工挖掘等全特性精英僵尸。
-   **🎨 现代美学视觉**：
    -   **Premium UI**：全屏自适应 7x10 大草坪，配合 3 列垂直植物卡槽。
    -   **矢量程序绘图**：所有角色均通过 Canvas 矢量算法动态绘制，运行时零资源加载，极致轻便。
-   **🛠️ 逻辑引擎重构**：
    -   **坐标驱动状态机**：弃用不稳定的连续物理碰撞，采用离散坐标判定逻辑，彻底解决“僵尸穿怪”和“层级混叠”的 Bug。
    -   **粒子特效系统**：子弹溅射、阳光轨迹、僵尸瓦解均拥有细腻的粒子反馈。

## 🛠 技术实现亮点

1.  **UIScene 独立解耦**：UI 界面与游戏场景物理层完全独立，通过 `Phaser.Registry` 实现阳光数值与卡片冷却状态的全局同步。
2.  **动态纹理生成**：`BootScene` 在启动时根据 `constants.js` 的颜色与形状配置，实时生成 WebGL 纹理，支持无限扩展新角色而不增加包体积。
3.  **高性能自定义更新器**：借鉴 ECS 模式，为每株植物分配独立的 `customUpdate` 钩子，优化了循环检测频率，即便同屏上百个单位也能稳定 60FPS。

## 📂 项目架构与文件说明

本项目采用模块化的场景管理模式，确保逻辑与渲染的高度解耦：

```text
427/
├── index.html          # 网页入口
├── package.json        # 依赖配置 (Phaser 3, Vite)
├── src/
│   ├── main.js         # 游戏主入口，配置 Phaser 实例与物理引擎
│   ├── constants.js    # 全局常量：核心定义 20 种植物与 10 种僵尸的属性
│   ├── mock/
│   │   └── levelData.js # 关卡配置：初始阳光、解锁植物及进攻波次
│   └── scenes/
│       ├── BootScene.js # 资源加载与纹理预研：代码绘制高性能角色贴图
│       ├── MenuScene.js # 主菜单场景：沉浸式背景与交互按钮
│       ├── PlayScene.js # 核心战斗逻辑：僵尸 AI、植物技能及坐标判定引擎
│       └── UIScene.js   # 玻璃拟态 UI 场景：侧边栏植物卡槽及阳光动态展示
```

1.  **数据驱动**：修改 `constants.js` 即可实现全员数值平衡调整。
2.  **高性能渲染**：通过 `BootScene` 动态生成纹理，减少了文件读取开销。
3.  **多层场景并行**：`PlayScene` 负责战斗核心，`UIScene` 固定在顶层负责交互，提供极佳的操控稳定性。
